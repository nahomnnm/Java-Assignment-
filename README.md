# Java OOP Product System

This is a simple Java project demonstrating basic Object-Oriented Programming (OOP) concepts.

## Features

* Base class: Product
* Subclass: ElectronicItem
* Methods:

  * purchase()
  * restock()
  * display()

## File Structure

* Product.java → Base class with common properties and methods
* ElectronicItem.java → Inherits from Product and adds warranty
* Main.java → Runs and tests the program

## How to Run

1. Compile:
   javac *.java

2. Run:
   java Main

## Concepts Used

* Inheritance
* Encapsulation
* Method Reuse
